# AquaFix Plumbing

A plumber booking website with a 3D animated hero, live appointment slots, a plumber profile, and a PIN-protected dashboard.

## Features

- Animated 3D hero section
- Live appointment slot selection
- Plumber profile
- PIN-protected dashboard

## Getting started

This is a single HTML file with no build step.

1. Download or clone this repository.
2. Open `AquaFix Plumbing.html` in any modern browser.

## Dashboard access

The dashboard is protected by a PIN. 

## Tech

Plain HTML, CSS, and JavaScript in one file.
